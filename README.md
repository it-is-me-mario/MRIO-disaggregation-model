# Multi Regional Input Output Tables sectorial disaggregation
Guided example of disaggregation of a sector in a MRIOT table using MARIO.

# Preliminary installations
It is suggested to create a specific Python environment since some features are not yet released in MARIO official release.

```bash
conda create -n mario python=3.12
```

Install MARIO from the GitHub repository: download or synchronize to the main branch https://github.com/it-is-me-mario/MARIO/tree/main

Use the following instructions in the prompt window to install MARIO:

```bash
cd your/path/of/the/MARIO/folder
pip install -e .
```

# How to use it
Download the provided Excel files GTAP12_example_db.xlsx and Inventory_example.xlsx and run the disaggregation routine in the notebook Run_example_disaggregation.ipynb
