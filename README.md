# Multi Regional Input Output Tables sectorial disaggregation
Guided example of disaggregation of a sector in a MRIOT table using MARIO.

Read this exercise on the [MARIO Tutorials site](https://tutorials.marioproject.com/mrio-disaggregation/).
This repository maintains the notebook and its Excel inputs. The site renders a
recorded source commit and provides the materials for download.

## Preliminary installations
Follow MARIO [installation instructions](https://mario-suite.readthedocs.io/en/latest/setup/index.html)

## How to use it
Download the provided Excel files GTAP12_example_db.xlsx and Inventory_example.xlsx and run the disaggregation routine in the notebook Run_example_disaggregation.ipynb

## Website publication

Changes to the notebook, README or Excel inputs on `main` request a new build of
the Tutorials site. The notification workflow uses the repository secret
`TUTORIALS_PUBLISH_TOKEN`, with Actions read/write permission limited to
`it-is-me-mario/Tutorials`. The Tutorials build records the exact source commit
and file hashes used in the published page.

For the publisher's maintenance and verification procedure, see
[Tutorials site maintenance](https://github.com/it-is-me-mario/Tutorials/blob/main/site/README.rst).
